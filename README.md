# Bootstrap v5.2.3 & Front-End Freelance Bootcamp

A 38-day, project-driven front-end engineering track focused on building fast, accessible, mobile-first websites and UI components using **Semantic HTML5**, **Modern CSS3**, **Vanilla JavaScript**, **Bootstrap v5.2.3**, **Bootstrap Icons**, and **Dart Sass**—tailored for freelance client delivery on **Fiverr** and **Freelancer.com**.

---

## Tech Stack & Standards

* **Core Markup & Styling:** Semantic HTML5, CSS3 (Box Model, Flexbox, Custom Properties, Mobile-First Media Queries)
* **Framework & Icons:** [Bootstrap v5.2.3](https://getbootstrap.com) (Zero-jQuery Bundle) & [Bootstrap Icons](https://getbootstrap.com)
* **Scripting:** Vanilla JavaScript (ES6+ DOM, Events, Bootstrap Instance APIs & Lifecycle Hooks)
* **Build & Optimization:** Dart Sass (`sass` with BS 5.2 `_maps.scss` architecture), PurgeCSS, and Google Lighthouse Audits
* **Quality Standards:** `360px` mobile-first responsiveness, WCAG/WAI-ARIA keyboard accessibility, Linux case-sensitive path hygiene, and zero console errors
